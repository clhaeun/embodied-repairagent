# Attribution and release review

This repository is based on collaborative research. The original source history includes multiple contributors, and a `clhaeun` commit does **not** prove sole authorship of every line in the file.

## Currently published

- Research description and **archived** evaluation summaries, with known limitations.
- Source provenance links, not copied collaborator commit history.

**Public visibility is not a license or confirmation of permission to republish code.** Code will be added only after the corresponding review.
